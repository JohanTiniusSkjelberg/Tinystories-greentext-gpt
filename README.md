# tinystories-greentext-gpt
I followed Karpathy's GPT from scratch video. I then built more functionality upon that. 
It is now capable of saving the model, with better tokenizer, bigger network and bigger dataset. 
I used Tinystories dataset with 2.1 million stories to train the network. I then used a homegrown wholesome greentext syntetic dataset to fine-tune the saved network. 

# Training stats
- TinyStories model: step 19,500, validation loss 1.82.
- Greentext model: step 4000, validation loss 2.79 on greentext.
